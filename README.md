## 🔐 Licensed installation

DAHOOM is distributed under a per-client license. The tool itself is not
published in plaintext — it ships as an encrypted bundle that only your
personal license key can unlock.

To install, use the **License ID** and **License Key** you were given:

```bash
FM_ID=owner bash <(curl -sL https://raw.githubusercontent.com/mooa322/fm/main/install.sh)
```

You can also just run the installer and it will prompt for the ID and key:

```bash
bash <(curl -sL https://raw.githubusercontent.com/mooa322/fm/main/install.sh)
```

The license is saved on the server, so future updates need no re-entry.

## 🖥️ Open the control panel

After installation, launch the interactive menu anytime with:

```bash
menu
```
